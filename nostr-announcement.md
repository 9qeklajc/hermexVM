**hermexVM**:

Hermes on your machine.  
@Routstr for open model routing.  
@contextVM over Nostr for the encrypted connection.

### What you can do in a conversation

- Chat with any configured Hermes agent and receive responses live.
- See thinking, status updates, tool calls, progress, output, and errors as they happen.
- Approve or reject sensitive tool actions and answer the agent’s clarification questions.
- Stop an active run at any time.
- Reply to or copy individual messages.
- Render rich Markdown, including code blocks and links.
- Attach images, audio, video, PDFs, archives, code, text, and other files.
- Record voice messages and turn them into an editable transcription before sending.
- Send selected messages or a full transcript to another agent, either as a new conversation or into an existing one.

### Features

- Multiple Hermes agent profiles.
- Persistent conversation history with automatic resume and live reattachment after connection drops.
- Model selection for each conversation.
- Project selection and project creation.
- Searchable Hermes skill picker, grouped by category.
- Linked conversation and agent-handoff history.
- Automatic upload retry and recovery from temporary relay failures.
- Explicit client allowlisting at the bridge.
- Android and web support—the web client can also be built and published as a Nostr nsite.
